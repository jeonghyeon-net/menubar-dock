# Menu Bar Dock

Apple Silicon Mac용 메뉴 막대 런처를 새로 만드는 프로젝트입니다.

현재는 설계 단계이며 실행 가능한 앱은 아직 없습니다. 기존 앱의 사용 경험을 참고하되, 상태 관리와 메뉴 막대 UI는 새로 구현합니다.

## 첫 버전의 핵심 동작

- 사용자가 정한 앱 순서를 재실행 후에도 유지합니다.
- 아이콘 사이에 시작 시 빈 슬롯이나 임의 구분선을 만들지 않습니다.
- 비활성 디스플레이에서도 macOS의 외관 설정에 맞게 표시합니다.
- 메뉴 막대에 실행 중 표시나 점을 넣지 않습니다.
- `Option+Tab` / `Shift+Option+Tab`으로 이동하고 `Enter`로 선택합니다.
- 이미 실행 중인 앱은 기존 창을 활성화합니다.
- 새 앱의 창 위치는 macOS와 대상 앱의 기본 동작을 따릅니다. 화면 간 자동 이동 기능은 제외합니다.

권장 기반은 **Swift 6 모드 + AppKit + SwiftUI 설정 화면**, 최소 macOS 14, arm64 배포입니다. 메뉴 막대의 비활성 디스플레이 외관과 키보드 포커스는 초기 프로토타입에서 먼저 검증합니다.
