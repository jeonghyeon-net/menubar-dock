# 사용 설명

## 설치와 시작

DMG를 연 뒤 Menu Bar Dock을 Applications 폴더로 옮겨 실행합니다. 처음 실행하면 설정이 나타납니다. 기존 EthanSK 앱을 함께 실행하면 두 앱이 각각 아이콘을 표시하므로 기존 앱은 직접 종료해 주세요. 이 앱은 기존 앱의 설정을 수정하지 않습니다.

로컬에서 빌드한 앱은 ad-hoc 서명입니다. Developer ID로 서명하고 Apple 공증을 받은 배포본과 구별해야 합니다. 공증되지 않은 다운로드 앱의 실행 여부는 macOS 보안 정책이 결정합니다.

## 앱과 순서

- **앱 추가**: 설치된 `.app`을 선택하면 고정합니다. 여러 앱을 한 번에 선택할 수 있습니다.
- **고정**: 종료된 앱도 계속 표시합니다.
- **제외**: 실행 중이어도 표시하지 않습니다.
- 목록을 드래그하거나 위/아래 버튼으로 순서를 바꿉니다. 앱 전환은 순서를 바꾸지 않습니다.
- 앱을 옮겨 경로가 끊어지면 “앱 경로 다시 지정”을 사용합니다.
- 실행 중 앱을 목록에서 제거하면 다시 자동 추가되지 않도록 제외합니다.

아이콘을 클릭하면 앱이 열립니다. 이미 실행 중이면 해당 설치본을 활성화하며 창 위치를 직접 변경하지 않습니다. 우클릭 메뉴에서 고정·제외·숨기기·표시·정상 종료·Finder에서 보기를 사용할 수 있습니다. 정상 종료는 대상 앱의 문서 저장 확인에 따라 취소될 수 있습니다.

## 메뉴 막대 공간

아이콘 크기·간격·최대 개수를 조절할 수 있습니다. 실제 표시할 아이콘 수만큼 폭을 사용하고 중간 빈 슬롯이나 실행 중 점을 만들지 않습니다. 표시 개수를 넘는 앱은 더 보기 메뉴와 키보드 선택 패널에서 열 수 있습니다.

접힌 모드는 런처 버튼 하나를 표시합니다. 노치나 다른 메뉴 때문에 전체 묶음이 보이지 않으면 단축키로 열거나 Finder에서 Menu Bar Dock을 다시 실행해 설정에 접근하세요. Command를 누르고 메뉴 막대 항목을 드래그하면 전체 묶음의 위치를 바꿉니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| Option+Tab | 다음 앱 선택, 패널이 닫혀 있으면 열기 |
| Shift+Option+Tab | 이전 앱 선택 |
| 방향키 | 패널 안에서 선택 이동 |
| Enter | 선택한 앱 열기 |
| Esc | 선택 취소 |

Option을 놓아도 자동 실행하지 않습니다. Enter로 선택을 확정합니다. 패널이 열린 동안 새 앱이 실행돼도 선택 순서는 바뀌지 않습니다.

설정에서 정방향/역방향 단축키를 각각 변경할 수 있습니다. 기록 버튼을 누른 뒤 조합을 입력하세요. Esc로 기록을 취소할 수 있습니다. 시스템이나 다른 앱과 충돌하면 다른 조합을 지정하세요. 기본값 복원은 두 조합을 함께 복원합니다.

## 로그인 시작과 업데이트

로그인 자동 시작은 앱을 Applications로 옮긴 뒤 켜는 것을 권장합니다. macOS가 승인을 요구하면 시스템 설정의 로그인 항목에서 허용합니다. 앱의 표시 상태는 시스템의 실제 등록 상태를 읽습니다.

업데이트 확인은 사용자가 눌렀을 때 GitHub의 최신 정식 릴리스를 확인합니다. 새 버전이 있으면 릴리스 페이지를 열 수 있습니다. 자동 설치와 사용 정보 전송은 하지 않습니다.

## 설정과 문제 해결

설정은 `~/Library/Application Support/net.jeonghyeon.MenuBarDock/`에 저장합니다. `preferences.json`과 정상 백업을 관리하며 손상 파일은 별도 이름으로 보존합니다. 더 최신 앱의 설정 형식을 만나면 원본을 보호하기 위해 읽기 전용으로 시작합니다.

전역 단축키 값은 `net.jeonghyeon.MenuBarDock` 사용자 기본 설정에 저장합니다. 기본 사용에 손쉬운 사용·화면 기록·입력 모니터링 권한이 필요하지 않습니다.

비활성 화면의 색상 문제를 제보할 때 앱/macOS 버전, 화면 배율, 활성/비활성 화면, 대비·투명도 설정을 함께 적어 주세요. 정상적인 macOS의 비활성 dimming은 시스템 동작입니다.
