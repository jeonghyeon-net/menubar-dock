# 사용 안내

## 설치와 시작

[최신 릴리스](https://github.com/jeonghyeon-net/menubar-dock/releases/latest)에서 DMG를 다운로드합니다. DMG 안의 **Menu Bar Dock**을 **Applications(응용 프로그램)** 폴더로 드래그한 뒤 실행하세요. 처음 실행하면 설정 창이 열립니다.

기존 EthanSK의 Menu Bar Dock을 함께 사용 중이면 종료해 주세요. 두 앱을 동시에 실행하면 메뉴 막대에 아이콘이 중복으로 나타납니다.

## 앱 열기와 설정

메뉴 막대의 앱 아이콘을 **왼쪽 클릭**하면 앱을 실행하거나 기존 앱으로 전환합니다.

설정은 `Command+Space` 패널의 **톱니 버튼을 왼쪽 클릭**해 엽니다. 아이콘 우클릭·Control-클릭 메뉴의 **설정** 또는 Finder에서 **Menu Bar Dock 재실행**으로도 열 수 있습니다.

설정 위쪽의 **항상 표시할 앱** 목록에서 앱과 순서를 관리합니다. 등록한 앱은 종료 후에도 메뉴 막대와 선택 패널에 남습니다.

| 조작 | 동작 |
| --- | --- |
| `+` | 앱을 목록 끝에 추가. 여러 앱을 함께 선택할 수 있음 |
| `−` | 선택한 앱의 고정 해제. 실행 중이면 앞쪽에 남고 종료하면 사라짐 |
| `↑`·`↓` 또는 행 드래그 | 등록한 앱의 순서 변경 |
| 행 두 번 클릭 | 앱 열기 |
| 더 보기 버튼 | **Finder에서 보기**, **앱 위치 다시 지정…** |

아이콘 메뉴는 **목록에 추가 → 설정 → 종료** 순서입니다. 등록한 앱에서는 첫 항목이 **목록에서 제거**로 바뀌며, 설정의 `−`와 같이 고정만 해제합니다.

## 자동 감지와 표시 순서

macOS Dock에 고정한 앱과 Finder는 자동으로 가져옵니다. 이후 Dock에 새로 추가한 앱은 **항상 표시할 앱** 목록 끝에 들어갑니다. 기존 순서는 유지하며, Dock에서 고정을 풀어도 이 목록에는 남습니다.

메뉴 막대와 선택 패널은 다음 순서로 표시합니다.

1. 등록하지 않은 실행 중 앱: 앞쪽에 표시하고, 종료하면 사라집니다.
2. **항상 표시할 앱**에 등록한 앱: 뒤쪽에 저장한 순서로 표시합니다.

같은 앱의 창이 여러 개여도 아이콘은 하나입니다. 고정을 해제한 앱은 Dock 동기화로 다시 고정되지 않습니다. **실행 중인 앱 자동 표시**를 끄면 등록한 앱만 표시합니다.

**Finder 숨기기**를 켜면 메뉴 막대와 기본 앱 선택 목록에서 Finder만 숨깁니다. 등록 상태와 순서는 유지하므로 끄면 원래 위치로 돌아옵니다. 숨긴 상태에서도 이름으로 검색해 열 수 있습니다.

## 크기와 간격

| 설정 | 기본값 | 조절 범위 |
| --- | --- | --- |
| 아이콘 크기 | 24pt | 16~32pt |
| 아이콘 간격 | 0pt | 0~28pt |
| 최대 표시 개수 | 6개 | 1~20개 |

간격 0pt에서도 macOS가 메뉴 막대 항목에 붙이는 기본 여백은 남습니다. **기본값** 버튼은 크기와 간격만 되돌립니다.

메뉴 막대에 다 들어가지 않는 앱은 `Command+Space` 패널에서 열 수 있습니다. 노치나 다른 메뉴에 가려지면 최대 표시 개수를 줄여 보세요.

## 키보드로 선택하기

| 키 | 동작 |
| --- | --- |
| `Command+Space` | 패널 열기 또는 다음 앱 선택 |
| `Shift+Command+Space` | 이전 앱 선택 |
| 방향키 | 앱 선택 이동. 검색 중에는 위·아래로 결과 선택, 좌·우로 글자 커서 이동 |
| `Enter` | 선택한 앱 열기 |
| `Esc` | 검색어 지우기. 검색어가 없으면 패널 닫기 |

Command 키를 놓아도 앱이 열리지 않습니다. **Enter**로 선택을 확정하세요.

단축키는 설정 아래쪽에서 바꿉니다. 현재 키 조합이 적힌 버튼을 누르고 새 조합을 입력하세요. **Esc**로 변경을 취소하고, **단축키 기본값**으로 두 조합을 복원합니다. **키보드로 앱 선택**을 끄면 단축키를 사용하지 않습니다.

### macOS 단축키 우선 사용

기본 `Command+Space`를 켜면 **시스템 설정 → 키보드 → 키보드 단축키 → Spotlight → Spotlight 검색 보기**의 같은 조합을 자동으로 해제합니다. 이후 이 키는 Menu Bar Dock의 앱 선택 패널을 엽니다. Spotlight의 앱 색인과 패널 안의 앱 검색은 계속 사용할 수 있습니다.

Spotlight를 다른 키로 설정했다면 그 조합은 유지합니다. 기존 기본 조합으로 저장된 설정은 새 기본값으로 자동 이전하고, 사용자가 지정한 다른 조합은 보존합니다.

앱을 종료하거나 **키보드로 앱 선택**을 꺼도 Spotlight 설정은 해제된 상태로 남습니다. Spotlight로 돌리려면 먼저 Menu Bar Dock의 단축키를 끄거나 다른 조합으로 바꾼 뒤, 위 시스템 설정에서 **Spotlight 검색 보기**를 다시 켜세요.

macOS 설정 적용에 실패하면 설정 창에 오류와 수동 해제 경로가 표시됩니다. 다른 앱도 `Command+Space`를 사용하면 해당 앱의 단축키를 바꾸거나 끄세요.

### Spotlight 검색

패널에서 이름을 입력하면 이 Mac의 앱을 검색합니다. 결과에는 아이콘과 앱 이름만 표시합니다. 위·아래 방향키 또는 `Command+Space`로 고른 뒤 **Enter**로 열거나, 결과를 왼쪽 클릭하세요. 검색어를 지우면 원래 앱 목록으로 돌아갑니다. 한글 입력 중 Enter는 먼저 글자를 확정합니다.

<p align="center">
  <img src="assets/search.png" width="420" alt="Finder, Safari, Terminal의 아이콘과 이름만 표시한 앱 검색 결과">

검색은 macOS Spotlight에 등록된 앱을 대상으로 합니다. Spotlight에서 제외한 위치나 아직 색인하지 않은 앱은 검색되지 않을 수 있습니다. 파일과 폴더는 검색하지 않습니다.

목록에서 제거한 앱도 검색할 수 있습니다. 검색으로 열어도 **항상 표시할 앱** 목록에는 추가되지 않습니다. 검색어와 결과는 저장하지 않습니다.

## 로그인 시작과 업데이트

설정의 **로그인할 때 시작**을 켜면 로그인할 때 Menu Bar Dock이 실행됩니다. 앱은 응용 프로그램 폴더에 설치해 두세요. macOS가 승인을 요구하면 시스템 설정의 로그인 항목에서 허용합니다.

설정 하단의 **업데이트**를 누르면 최신 릴리스를 확인합니다. 새 버전은 릴리스 페이지에서 다운로드해 설치하세요. 설치 전에 실행 중인 Menu Bar Dock을 종료하면 됩니다. **종료** 버튼은 설정 하단과 아이콘 우클릭 메뉴에 있습니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 설정을 열 수 없음 | 응용 프로그램 폴더에서 Menu Bar Dock을 다시 실행 |
| 일부 앱이 메뉴 막대에 안 보임 | `Command+Space`로 전체 목록 확인. 설정의 최대 표시 개수 조절 |
| 실행 중인 미등록 앱이 안 보임 | **실행 중인 앱 자동 표시**를 켜고 `Command+Space`에서 확인 |
| 단축키가 동작하지 않음 | 설정의 **키보드로 앱 선택** 확인. Spotlight 설정 오류 안내를 해결하고, 같은 키를 쓰는 다른 앱의 단축키 해제 |
| 이동한 앱을 열 수 없음 | 목록에서 앱을 선택하고 더 보기의 **앱 위치 다시 지정…** 사용 |
| 로그인 시작을 켤 수 없음 | 앱이 응용 프로그램 폴더에 설치되어 있는지 확인 |

문제가 계속되면 [버그 보고](https://github.com/jeonghyeon-net/menubar-dock/issues/new?template=bug_report.yml)에 앱·macOS 버전과 재현 방법을 알려 주세요. 화면 색상 문제에는 화면 배율과 활성·비활성 여부도 적어 주세요.
