# 1.0.7 ⌘ Space 검증

날짜: 2026-09-30. macOS 27.0, Apple Silicon, Apple Swift 6.4 / Command Line Tools에서 수행했다.

## 변경 범위

기본 단축키를 ⌘ Space / ⇧⌘ Space로 바꾸고 이전 기본값 두 개만 한 번 이전한다. 같은 키를 쓰는 Spotlight 설정을 해제한 다음 Carbon에 등록한다. 사용자 지정 Spotlight 키·다른 시스템 설정은 보존하고 등록 실패 시 이번 설정 변경을 복구한다. 선택 패널은 현재 조합에 해당하는 입력만 소비한다.

Spectacle과 Rectangle/MASShortcut의 원문 소스, 일반 등록과 시스템 충돌 검사를 선택한 근거는 [설계 결정](../adr/0005-command-space-override.md)에 있다.

## 배포와 미확인 범위

릴리스는 문서까지 커밋·푸시한 최종 main에서 `mise run release`로 다시 검사·패키징한다. 게시 도구는 첨부 파일을 다시 내려받아 원본과 비교하고 기존 공개 태그·파일을 덮어쓰지 않는다.

서명은 ad-hoc이며 Developer ID 서명·Apple 공증은 수행하지 않았다. 물리 키보드 입력, macOS 14–26 전체, 다른 런처와 같은 조합을 동시에 사용하는 모든 경우, 다중 화면·Spaces/fullscreen·재부팅은 이 결과만으로 검증됐다고 보지 않는다. 내부 설정 적용 도구가 없는 OS에서는 오류와 수동 설정 경로를 안내한다.
