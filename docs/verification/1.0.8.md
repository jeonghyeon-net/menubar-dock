# 1.0.8 여러 앱 숨김 검증

날짜: 2026-10-07. macOS 27.0, Apple Silicon, Apple Swift 6.4에서 수행했다. 기능 커밋은 `41fc615`이며 문서까지 포함한 최종 main은 릴리스 명령에서 같은 검사와 패키징을 다시 수행한다.

## 변경 범위

Finder 전용 숨김을 등록 목록과 독립된 `hiddenApps`로 확장했다. 실행 중·등록 앱은 메뉴에서 고르고 다른 앱은 다중 파일 선택으로 추가한다. 설정은 항상 표시할 앱과 숨길 앱을 한 창에 나란히 놓고, 숨겨진 등록 행에 상태를 표시한다. 여러 숨김 행을 선택해 한 번에 해제할 수 있다.

숨김은 메뉴 막대·기본 앱 전환 후보만 거르며 등록·고정 해제·순서는 보존한다. 이름 검색에는 적용하지 않는다. bundle identifier가 같은 설치본은 함께 숨기고 identifier가 없으면 설치 경로로 구분한다. schema 3은 v1·v2를 읽고 Finder 전용 설정을 경고 없이 이전한다.

## 문서 화면과 배포

[설정 화면](../assets/settings.png)은 개인 데이터 없이 시스템 앱 6개와 Finder·Terminal 숨김 예시를 실제 AppKit 뷰에 넣어 렌더링했다. 두 목록·상태·버튼·슬라이더·단축키·버전 1.0.8의 표시를 확인했다. 이전 1.0.7 화면은 별도 이미지로 보존했다.

`mise run release`는 최종 main의 로컬 검증, 격리된 앱 빌드, ZIP·DMG 검사, 시작·저장·정상 종료 검사 후 게시한다. 업로드한 첨부 파일을 다시 내려받아 로컬 원본과 비교하며 기존 공개 태그·파일을 덮어쓰지 않는다.

서명은 ad-hoc이며 Developer ID 서명·Apple 공증은 수행하지 않았다. 다른 macOS 버전·다중 화면·Spaces·재부팅은 이번 결과에 포함하지 않는다.
