# 등록 목록과 실행 앱 분리 검증

설정은 **항상 표시할 앱** 한 열로 구성한다. 추가한 앱은 종료 후에도 남고, 드래그·위아래 이동으로 정한 순서를 유지한다. 미등록 실행 앱은 이 목록 앞에 표시하며 등록 앱과 중복되지 않는다.

## 확인한 경계

- 설정 행 인덱스와 전체 catalog 인덱스가 달라도 등록 앱만 이동한다. 임시·숨김 이력의 위치를 보존하며 모든 단일 이동 조합과 다중 이동을 검사했다.
- 임시 앱 등록은 목록 끝에 추가한다. 반복 추가는 ID와 순서를 유지한다.
- `−`와 아이콘 메뉴의 제거 명령은 삭제 기록을 남긴다. 실행·Dock 변경·재시작으로 복원하지 않으며, 명시적 `+`로 복원한다.
- 삭제한 앱을 실행 중 이동해도 새 경로를 발견한 배치에서 bookmark를 복구한다. 이미 알려진 삭제 경로는 다시 조회하지 않는다.
- 위치 재지정 대상이 임시 실행 항목이면 원래 등록 ID·순서에 합친다. 다른 등록 앱과 충돌하거나 선택 도중 원래 행이 삭제되면 기존 상태를 보존하고 오류를 반환한다.
- 이전 `isPinned`·`isExcluded`와 삭제 기록은 저장 호환을 위해 유지한다. 저장 schema를 변경하지 않는다.

## 자동 검증

`./scripts/check.sh` 통과:

| 검사 | 결과 |
| --- | --- |
| Swift 테스트 | 185개 통과: UI·조립 61, 단축키 15, 플랫폼 48, 저장 29, 도메인 32 |
| 릴리스 도구 | 78개 통과 |
| 실제 상태 버튼 입력 | 독립 버튼 8개의 왼클릭·우클릭·Control 클릭·접근성 press 통과 |
| 아이콘 렌더링 | 16·20·24·28·32pt의 실제 픽셀 면적 증가 확인 |
| 실제 슬라이더 추적 | 크기·간격 각각 17회, 트랙 밖 이동과 최종 저장 확인 |
| 검색 입력 | 포커스·방향키·Enter·Esc·Option+Tab·한글 조합·취소와 늦은 응답 검사 통과 |

설정 이미지도 제품 뷰로 다시 생성해 단일 열과 버전 표시를 확인했다. 개인 설정 대신 공개된 시스템 앱 6개를 사용한다.

```sh
./scripts/check-settings-input.sh --snapshot docs/assets/settings.png
```

공개된 v1.0.3 릴리스와 첨부 파일은 변경하지 않는다. [이전 설정 이미지](../assets/settings-1.0.3.png)는 해당 버전의 검증 기록에 보존한다.
