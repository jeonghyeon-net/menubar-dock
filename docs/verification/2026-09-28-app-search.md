# 앱 전용 검색과 결과 표시 검증

Option+Tab 검색 범위를 실행 가능한 앱으로 제한하고, 결과 행은 아이콘과 앱 이름 한 줄로 구성했다. 기존 Spotlight 통합 검증 이후 변경된 정책이다.

## 재현과 수정

수정 전 실제 Spotlight 인덱스를 제품의 `SpotlightSearchService`로 조회했다. `safa` 검색의 결과 50개 중 48개가 SDK·framework·tbd 항목이었다. SDK 프레임워크와 링크 스텁이 결과 변환에서 통과하는 회귀 테스트도 먼저 실패하는 것을 확인했다.

조회 조건에 앱 번들 타입을 추가하고 결과 변환에서도 실행 가능한 앱인지 검증했다. SDK·플러그인·다른 앱 번들 안의 보조 앱은 제외한다. Finder·Safari와 독립 설치 앱은 유지한다. 앱을 선택한 뒤 이동·삭제·교체된 경우에도 실행 직전에 다시 검증한다.

`Application Support`와 `/usr/local`에 설치한 독립 앱도 유지한다. 두 위치와 그곳을 가리키는 설치 링크의 회귀 검사에서 수정 전 6개 실패를 재현한 뒤 경로 정책을 보정했다. 같은 위치의 앱 내부 보조 앱은 계속 제외한다.

수정 후 같은 `safa` 검색은 **Safari 1개, SDK·framework·tbd 0개**를 반환했다. 별도의 고유 이름으로 앱·일반 문서·폴더·프레임워크·링크 스텁을 만든 뒤 실제 Spotlight 인덱스에서 검색해도 앱 1개만 반환했다. 검사 후 임시 자료는 삭제했다. 이 조회 검사는 검색된 앱을 실행하지 않는다.

## 화면과 입력

- 앱 이름 15pt와 아이콘 32pt를 한 줄의 수직 중앙에 배치한다.
- 경로·보조 텍스트·경로 툴팁을 제거했다. 접근성 이름도 앱 이름만 읽는다.
- 결과가 적으면 창 높이를 줄이며 마지막 행이 잘리지 않는다.
- 입력 포커스, 빈 영역 클릭 후 입력, 커서 이동, 방향키·Enter·Esc·Option+Tab, 한글 조합 확정, 이전 검색 응답 무시를 실제 네이티브 입력 도구로 검사했다.
- [앱 검색 화면](../assets/search.png)과 [앱 선택 화면](../assets/switcher.png)은 제품 뷰를 시스템 앱으로 렌더링했다. 개인 검색 결과는 포함하지 않는다.

## 검증 결과

`./scripts/check.sh` 통과:

| 검사 | 결과 |
| --- | --- |
| Swift 테스트 | 191개: UI·조립 62, 단축키 15, 플랫폼 53, 저장 29, 도메인 32 |
| 릴리스 도구 | 78개 |
| 실제 상태 버튼 입력·아이콘 렌더링 | 통과 |
| 실제 크기·간격 슬라이더 추적 | 각각 17회 통과 |
| 실제 검색 입력·한글 조합·단일 행 배치 | 통과 |
| 제품 서비스와 실제 Spotlight 인덱스 | Safari 유지, 비앱 결과 제외 |

최종 설치 경로 보정 뒤 플랫폼 검색·정책 테스트 23개를 다시 실행해 통과했다. 이때 설치 링크 회귀 1개를 추가해 전체 테스트 수는 192개가 되었다.

플랫폼 회귀 검사는 `SpotlightSearchTests`와 `SpotlightResultPolicyTests`, 화면 회귀 검사는 `NativeUIBehaviorTests`에서 실행한다. 공개 v1.0.3 릴리스는 변경하지 않는다.
