## v1.0.3 공개 결과

[v1.0.3](https://github.com/jeonghyeon-net/menubar-dock/releases/tag/v1.0.3)을 2026-09-28 15:03 KST에 정식 최신 릴리스로 게시했다. 대상은 `bdeed931e91536d375862214eb36fef4da310d2d`, 빌드 번호는 `20`, 서명은 ad-hoc이다.

ZIP·DMG·`SHA256SUMS`·`release-manifest.json` 네 파일을 인증 없는 공개 다운로드 URL에서 다시 내려받았다. 로컬 원본과 바이트 단위로 일치하며 GitHub의 파일별 SHA-256 및 manifest 검증도 통과했다. latest API에서 `v1.0.3`, `draft=false`, `prerelease=false`를 확인했다.

첫 게시 시 초안 생성 직후 목록 API에 반영이 지연되어 중단됐다. 같은 초안과 로컬 파일을 보존한 채 재실행하여 게시를 완료했다. 이 사례를 릴리스 도구의 제한된 재조회와 회귀 검사에 반영했다. 생성·업로드·공개 뒤의 조회 지연을 재현하고, 최대 4회 조회·쓰기 중복 방지·실패 시 원본 보존을 검증했다. 이미 공개한 태그와 배포 파일은 변경하지 않았다.

## 한계

실제 Developer ID 인증서와 Apple 공증 제출은 수행하지 않았다. 서명 상태의 분류와 미완료 공증을 완료로 표시하지 않는 경계는 대역 검사로 구분한다. 새 Mac에서 다운로드한 파일의 최초 설치, Gatekeeper 허용, 지원 macOS 버전별 실기기 확인은 별도다.

공개 릴리스의 생성 여부는 테스트 결과와 구별한다. `release-plan`은 조회만, `release-prepare`는 검증된 로컬 파일 생성까지만 수행한다. 실제 게시 결과는 해당 GitHub Release의 대상 커밋·첨부 파일·본문으로 확인한다. 실행 절차는 [빌드와 릴리스](../releasing.md)에 있다.
