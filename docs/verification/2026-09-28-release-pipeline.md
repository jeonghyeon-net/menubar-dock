# 로컬 릴리스 도구 검증

2026-09-28 · Apple Silicon Mac, macOS 27, Swift 6.2 이상 도구 체인.

## 구성

태그 기반 버전 계산, 한국어 릴리스 노트, 격리된 arm64 앱 빌드, ZIP·DMG·체크섬·manifest, GitHub 초안 업로드와 검증 후 공개 절차를 추가했다. GitHub Actions와 PR은 추가하지 않았다.

## 확인한 범위

| 검사 | 결과 |
| --- | --- |
| 버전·노트 | 임시 Git 이력에서 최초·다음·정확한 태그, 다른 계보, 충돌·overflow·shallow 이력, 변경 범위, Markdown 구두점, manifest 불일치 거부 통과 |
| 게시 경계 | 변경된 작업 트리·브랜치·원격·커밋·태그, 인증·업로드·다운로드 실패, 초안 재개, 기존 공개 파일 보존, 조회 전용 무변경을 명령 대역으로 검증 |
| GitHub 조회 | 초안을 포함하는 페이지 목록 API 사용. 실제 저장소의 빈 릴리스 목록 응답 확인. 사용자 정의 GH_HOST에 영향을 받지 않도록 고정 |
| Swift | 경고를 오류로 처리하는 빌드, 기존 142개 자동 테스트 통과 |

| 패키징 | 실행 중인 개발 앱과 다른 폴더에 arm64 Release 번들 생성, ad-hoc 서명·버전·빌드 번호·Git 커밋 확인 |
| ZIP·DMG | 실제 ZIP 추출과 DMG 읽기 전용 마운트, 두 번들의 파일 일치·서명·리소스·자체 진단, Applications 링크, 체크섬 확인 |
| 앱 수명 | 생성한 앱의 임시 설정에서 시작·저장·정상 종료, 기존 사용자 설정 미변경 확인 |

## 한계

실제 Developer ID 인증서와 Apple 공증 제출은 수행하지 않았다. 서명 상태의 분류와 미완료 공증을 완료로 표시하지 않는 경계는 대역 검사로 구분한다. 새 Mac에서 다운로드한 파일의 최초 설치, Gatekeeper 허용, 지원 macOS 버전별 실기기 확인은 별도다.

공개 릴리스의 생성 여부는 테스트 결과와 구별한다. `release-plan`은 조회만, `release-prepare`는 검증된 로컬 파일 생성까지만 수행한다. 실제 게시 결과는 해당 GitHub Release의 대상 커밋·첨부 파일·본문으로 확인한다. 실행 절차는 [빌드와 릴리스](../releasing.md)에 있다.
